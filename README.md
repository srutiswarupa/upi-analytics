# UPI Transactions 2024 Digital Payment Analytics

## 📌 Project Overview
This project analyzes the UPI Transactions 2024 dataset using Python in Google Colab. The goal is to understand transaction patterns, payment behavior, merchant categories, transaction amounts, fraud occurrences, and peak transaction hours through Exploratory Data Analysis (EDA).

## 🎯 Objective
- Analyze UPI transaction trends.
- Study transaction types and merchant categories.
- Examine transaction amounts.
- Analyze fraud occurrences.
- Identify peak transaction hours.
- Generate business insights and recommendations.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## 📊 Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Transaction Status Analysis
- Transaction Type Analysis
- Merchant Category Analysis
- Transaction Amount Analysis
- Fraud Analysis
- Hour of Day Analysis
- Business Insights & Recommendations

## 📈 Key Findings
- Most UPI transactions were completed successfully.
- P2P transactions were the most common transaction type.
- Grocery was the leading merchant category.
- The average transaction amount was approximately ₹1,311.76.
- Fraudulent transactions were very low compared to total transactions.
- Transaction activity peaked during the evening hours.

## 💡 Business Recommendations
- Maintain a high transaction success rate to improve customer satisfaction.
- Strengthen fraud detection for suspicious transactions.
- Ensure adequate server capacity during peak transaction hours.
- Improve digital payment services for high-demand merchant categories.
- Encourage digital payment adoption in lower-usage sectors.

## 📝 Conclusion
The analysis provides valuable insights into UPI transaction patterns, customer behavior, and digital payment trends. These findings can help payment service providers improve operational efficiency, enhance security, and deliver a better user experience.
